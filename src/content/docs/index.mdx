## A glass box, not a black box

A typical compiler exposes only its source input and its final output; the
stages in between are not observable. saQut exposes each stage as a separate
command that produces a named, machine-readable result:

```bash
saqut tokens  hello.sqt     # token stream      (JSON)
saqut ast     hello.sqt     # abstract syntax tree (JSON)
saqut symbols hello.sqt     # symbol table      (JSON)
saqut ir      hello.sqt     # 3-address IR
saqut run     hello.sqt     # compile & execute
```

The language is deliberately small and C-flavoured. It exists to give the
inspectable pipeline something to compile.

## Your first program

<Steps>

1. **Write** a file called `hello.sqt`:

   ```c
   int main() {
       print("Hello, saQut!");
       return 0;
   }
   ```

2. **Run** it (no `class` or boilerplate needed); execution starts at `main`:

   ```bash
   saqut run hello.sqt
   ```

3. **Look inside** at any stage you're curious about:

   ```bash
   saqut ast hello.sqt --json
   ```

</Steps>

The [Getting Started](/getting-started/) guide covers building the compiler
and writing longer programs.

## A glimpse of the language

```c
int fibonacci(int n) {
    if (n <= 1) {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    print(fibonacci(10));   // 55
    return 0;
}
```

Functions, control flow, and `print()`. No mandatory scaffolding.

## How saQut is built

<CardGrid stagger>
  <Card title="Glass box pipeline" icon="open-book">
    Tokens, AST, symbol table, and IR are each a named, machine-readable
    output. Pipe `saqut ast` into your own tool, diff the optimized tree, or
    build an LSP from `saqut symbols` alone.
  </Card>
  <Card title="Procedural and explicit" icon="pencil">
    C-family syntax. No OOP, no generics, no hidden type coercion. Integer and
    float mixing follows one stated rule. The compiler runs what you wrote.
  </Card>
  <Card title="Value and reference, no pointers" icon="setting">
    Primitives (`int`, `float`, `bool`, `byte`) copy. Compounds (`string`,
    `struct`, `array`) share by reference. There is no user-visible `&` or `*`.
  </Card>
  <Card title="Nullable is opt-in" icon="approve-check">
    A value is non-null unless you declare it <code>T?</code>. The type checker
    verifies that a non-null value cannot be null before you use it, so there is
    no null check at run time.
  </Card>
  <Card title="Deterministic VM" icon="random">
    The bytecode VM is the reference backend: the same input produces the same
    output on every run. LLVM is intentionally not used. An experimental MIR JIT
    runs via <code>--jit</code>; embedded-runtime AOT is planned next.
  </Card>
  <Card title="Catchable errors" icon="error">
    <code>try</code> / <code>catch</code> / <code>throw</code> with struct-based
    errors. Out-of-bounds access, divide-by-zero, and null derefs raise a
    catchable error instead of terminating the program silently.
  </Card>
</CardGrid>

## The pipeline, end to end

```
Source -> Tokenizer -> Parser -> AST -> Symbol Collector -> Type Checker
  -> Optimizer (constant folding + DCE) -> IR Generator -> Bytecode VM -> output
```

Each arrow corresponds to a CLI command you can run and inspect.

### July 29, 2026 · 0.9.0 · Say What You Mean

- `77e9276` | The parser now reports a clear error for a missing closing
  `)`, `]`, or `}` in 25 different situations.
- `a01f46e` | `run`, `check`, and `ir` now all return the same exit code
  for the same kind of error, no matter which one you use.
- `c7d1d94` | `exec` now reports parser errors instead of silently
  continuing.
- `fe90c0c` | `ast` and `symbols` now report parser errors the same way
  `exec` and `run` do.
- `74e01a5` | `saqut ir` now shows every instruction kind in its output.
- `c43e830` | When a function ends without an explicit `return`, `saqut
  ir` now shows that implicit return too.
- `b48e0cf` | `saqut ir` now only prints color codes when the output goes
  to a real terminal, keeping piped or redirected output clean.
- `f7a32f9` | The compiler now correctly recognizes when every branch of
  a `switch` returns a value.
- `54881c8` | Indexing a non-array value with `[index]` is now rejected
  at compile time.
- `7f871b7` | Adds a differential test harness that automatically checks
  the VM and JIT agree on every result.
- `2f31cb2` | Makes `int32`, `longint64`, `float32`, and `double64` behave
  identically on the VM and the JIT.

### July 16, 2026 · 0.8.0 🏆 · The Experimental JIT's First Breath

  `--allow-net`, or `--allow-sys`.
- `1e0fbd3` | Adds `caps::drop` and `caps::has`: a running program can
  voluntarily give up permissions or check which ones it currently has.
- `04d90b5` | When a variable inside a block shadows one with the same

  one.

### July 14, 2026 · 0.6.0 · Small, Sharp, And Deliberate
