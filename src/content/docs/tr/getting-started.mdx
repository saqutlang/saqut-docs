Bu rehber, derleyiciyi edinmeyi, hangi platformların desteklendiğini ve bir
saQut projesinin temel yapısını anlatır. Önce doğrudan kod yazmaya başlamak
isterseniz [Merhaba Dünya](/tr/hello-world/) sayfasına gidin.

## saQut'u edinin

İki seçeneğiniz var: kaynak koddan derleyebilir ya da hazır sürümü
indirebilirsiniz.

### 1. Hazır sürümü indirin (önerilen)

Aşağıdaki platformlar için önceden derlenmiş ikili dosyalar yayınlanmaktadır:

| Platform | Mimari | Durum |
|---|---|---|
| Linux (tüm dağıtımlar) | x86-64 | Destekleniyor |
| Windows 11 | x86-64 | Destekleniyor |

[GitHub Releases](https://github.com/saqutlang/saqut/releases) sayfasından en
son sürümü indirin. Arşivi açtıktan sonra ikili dosyayı doğrudan
çalıştırabilirsiniz:

```bash
./saqut --help
```

Kurulum gerektirmez, sisteme bağımlılık eklemez. Tek başına çalışan bir
ikili dosyadır.

### 2. Kaynak koddan derleyin

saQut'u kendiniz derlemek isterseniz **C++17**, **CMake >= 3.16** ve **Ninja**
gereklidir.

```bash
git clone https://github.com/saqutlang/saqut
cd saqut
cmake -B build -G Ninja
cmake --build build
```

Derlenen ikili dosya `build/saqut` altında oluşur.

```bash
./build/saqut --help
```

Kullanılabilir komutların listesini görmelisiniz.

## Desteklenen platformlar

saQut, Linux x86-64 ve Windows 11 x86-64 sistemlerini hedefler. Derleyici
içinde platforma özgü kod bulunmaz; yalnızca standart C++17 ve taşınabilir
kütüphaneler kullanılır. ARM (aarch64) ve diğer mimariler ileriki bir sürüm
için planlanmaktadır ancak henüz yayınlanmamıştır. macOS bir hedef değildir
ve desteklenmeyecektir.

Test edilmemiş bir platformda sorunla karşılaşırsanız işletim sisteminizi,
mimarinizi ve derleyici sürümünüzü belirterek [issue
açabilirsiniz](https://github.com/saqutlang/saqut/issues).

## Program yapısı

Bir saQut programı, **fonksiyon tanımları** ve **global değişken
bildirimlerinden** oluşan bir listedir. Zorunlu bir `class` ya da hazır kalıp
kod yoktur; yürütme `main` adlı fonksiyondan başlar.

```c
// Önce fonksiyon tanımları gelir
int selamla(string isim) {
    print("Merhaba");
    print(isim);
    return 0;
}

// Ardından giriş noktası
int main() {
    selamla("saQut");
    return 0;
}
```

Her ifade `;` ile sonlanır. Bloklar `{ }` ile sarılır.

## `print()` fonksiyonu

`print()` yerleşik bir **konak fonksiyondur**: saQut koduyla değil, bizzat
derleyicinin içinde C++ ile gerçeklenmiştir. Herhangi bir türde tek bir
argüman alır ve onu terminale yazar:

```c
print(42);           // tamsayı
print(3.14);         // ondalıklı sayı
print("metin");      // metin
print(true);         // mantıksal, "1" ya da "0" çıktısı verir
```
